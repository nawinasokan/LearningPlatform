IMPORTANT

Code Execution Sandbox — Python code from the Coding Lab will run in an isolated subprocess with strict timeouts and resource limits (no Docker-in-Docker). This is safe for a local dev environment. For production, a separate Docker container or Pyodide (browser-side WASM) would be more secure. Which approach do you prefer?

Option A: Subprocess with resource limits (simpler, works immediately)
Option B: Pyodide (runs Python in browser, zero server risk)
NOTE

SQL Sandbox — SQL exercises will run against a separate read-only PostgreSQL schema (sandbox) pre-loaded with sample datasets (employees, orders, banking). This is isolated from the main application database.

NOTE

Seed content — All 860+ questions and explanations will be written as Python seed data files and inserted via Alembic seed migration. Content will be curated and accurate — this is the most time-intensive part of the project.
